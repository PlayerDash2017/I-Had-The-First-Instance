# I Had The First Instance

**Maker**: PlayerDash2017
**Engine**: Verve Engine (GMS2 Ported)  
**Tool**: GameMaker Studio 2

An avoidance game originally made in Studio 1 and ported to Studio 2, it contains a basic practice mode, multiple creative attacks, and Studio 1 code adapted for Studio 2.
